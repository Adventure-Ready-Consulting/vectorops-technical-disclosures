# VectorOPS Technical Disclosures

This repository contains public technical disclosures documenting systems, methods, processing workflows, and design concepts developed for VectorOPS by Adventure Ready Consulting.

## Authors and Inventors

- David Boyce
- Laetitia Gerard

Initial VectorOPS development began in May 2026.

## Purpose

This repository creates a public, dated, and versioned record of VectorOPS technical developments.

Each disclosure is intended to describe the identified systems and methods with sufficient technical detail to document their design, operation, and contemplated alternatives.

Disclosures may cover subjects including:

- Mission-aware processing of recorded and streaming sensor video
- Adaptive processing based on operational completion deadlines
- Computer-vision detection and candidate prioritization
- Multi-stage artificial-intelligence review
- Operator-directed investigative searching
- Detection-location and confidence refinement
- Video-frame, telemetry, and geographic-data association
- Search-and-rescue event review and prioritization
- Distribution of findings to TAK, SARTopo, and other operational systems
- Edge, local, cloud, and hybrid processing arrangements
